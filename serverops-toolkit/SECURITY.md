# 보안 및 운영 주의사항

ServerOps v0.2의 진단 기능은 의도적으로 **읽기 전용 진단 도구**로 설계되어 있습니다. 운영체제 상태, 소켓, 서비스 및 지정 로그 파일을 확인하지만 서비스를 재시작하거나 설정파일을 수정하거나 삭제 명령을 실행하지 않습니다.

## 인증정보

- `servers.json`에 SSH 비밀번호를 저장하지 마세요. SSH Key 또는 운영체제의 안전한 자격증명 저장소를 우선 사용하세요.
- DB 비밀번호를 `serverops.json`에 저장하지 마세요.
- MariaDB 점검은 `~/.my.cnf`, Unix Socket 인증 등 서버에서 사용하는 일반적인 클라이언트 인증 방식을 이용하는 것을 권장합니다.
- 생성된 리포트를 외부에 공유하기 전에 호스트명, IP 주소, 사용자명, 내부 경로, 애플리케이션 로그 등 민감한 운영 정보가 포함되어 있는지 확인하세요.

## 운영 서버 적용

가능하면 비운영 서버에서 먼저 테스트하세요. 일부 명령은 프로세스 또는 소켓의 전체 정보를 표시하기 위해 관리자 권한이 필요할 수 있습니다.

향후 서비스 재시작/설정 변경 기능을 추가한다면 최소한 다음 안전장치를 함께 구현하는 것이 좋습니다.

- 실행 전 사용자 확인
- 변경 전 설정 백업
- 허용된 서비스/경로만 조작하는 Allowlist
- 변경 이력 및 감사 로그
- 실제 변경 없이 결과만 보여주는 Dry-run
